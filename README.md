# 厨房助手（kitchen-assistant）

教厨房小白 log 做好吃的菜的个人 PWA 工具。以「拿到任何常见食材不慌、做得好吃」为目标的**教学化菜谱 + 食材知识 + 可迁移原理**体系。

- **纯静态**，无后端，无 AI 依赖（AI 对话粒度不可控，已被用户验证失败）
- **定位**：教学 > 菜谱。状态信号代替时间、锚点翻译代替量、熟后预览代替体积直觉
- **详细交接**：`HANDOFF.md`（设计体系、关键决策、已知坑，接手必读）

## 文件结构

| 文件 | 职责 |
|---|---|
| `index.html` | 单页应用，全部 UI/CSS/JS 内联 |
| `recipes.js` | 56 道菜数据，教学化结构（全局 `RECIPES`） |
| `knowledge.js` | 9 张原理卡 + 12 张食材卡（全局 `PRINCIPLES` / `INGREDIENTS`） |
| `sw.js` | PWA 离线缓存（v2，cache-first） |
| `manifest.json` | PWA 清单 |
| `start-server.cmd` / `.ps1` | 一键启动本地服务，手机同 WiFi 访问 |

## 使用方式

1. 双击 `start-server.cmd`（自动显示电脑/手机访问地址）
2. 手机同 WiFi 打开 `http://<电脑IP>:8123` → 菜单「添加到主屏幕」→ 离线可用
3. 内容更新后需在家重新打开一次刷新缓存

## 设计体系（定稿，不可随意偏离）

**三支柱**：
1. 状态信号代替时间——熟没熟看食材自身变化，时间只作括号参考
2. 锚点翻译代替量——「一勺」翻译成他家真实量具（汤勺/瓶盖/蛋壳量水），量一律「区间+比例+目测」
3. 熟后预览代替体积直觉——生熟比、出锅量（yield）、目标比例

**两条纪律**：备料先行、安全底线（涉油四件套 + 油锅起火处理）

**四个教学武器**：味道验收三问 / 权威口径 / 从中间进入 / 活物先麻醉

## 关键决策（已拍板）

- **库存功能：砍掉**（手动库存两周后必然失真，用户否决过，别再复活）
- 变体 = 改造版注记挂主菜谱（C 方案），不写独立变体菜谱
- 外部菜谱只能当骨架参考（老乡鸡 CookLikeHOC = 餐厅配方，教学层抄不了；下一参考源 HowToCook）
- 量基准：家常量 2-3 人份、一锅吃两顿；用户灶具 = 燃气灶 + 一口不粘锅一口铁锅
